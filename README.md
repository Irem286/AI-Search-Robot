# 🤖 AI Search Robot

AI Search Robot is a personal AI assistant project designed to provide intelligent answers through a modern and interactive web interface.

This project was built as part of my journey into Artificial Intelligence and software development.

## ✨ Features

- 💬 AI-powered question and answer system
- 🧠 Conversation memory
- 🎤 Voice input
- 🔊 Text-to-speech support
- 🌍 Language options
- 🌙 Modern dark interface
- 🖥️ Local AI processing with Ollama

## 🛠️ Technologies

- Python
- HTML
- CSS
- JavaScript
- Ollama


## 🚀 How It Works

The web interface allows users to enter questions and communicate with the AI assistant.

The Python backend sends the conversation to a locally running Ollama language model and returns the generated response to the interface.

## 🎯 Project Goal

The goal of this project is to explore how artificial intelligence models can be integrated with web technologies to create interactive AI applications.

I plan to continue improving this project by adding new features and expanding its capabilities.
